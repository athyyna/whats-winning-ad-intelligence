Competitor ad research · Swipe file

What's winning — and how you can tell

Competitor research isn't difficult, it's just painfully manual: open the Ad Library, search the brand, scroll, screenshot everything into a messy doc. This view turns that into a sortable swipe file — and judges “winning” by the one signal the libraries actually publish: longevity. An advertiser doesn't keep paying for a loser.

1 · Look up a brand

Amazon, Google and TikTok are pre-loaded samples from the July 2026 audit — look one up and its top ads appear right below, and the swipe file in section 4 filters to that brand only. Enter any other brand or domain and clicking “Show top ads” does the same: the whole page follows that brand, and a fresh capture starts for it on the spot — library searches built from what you typed, and a top-ads list that fills as you add what you find. If the brand has no captured ads yet, the swipe file shows its capture-started state instead of other brands' cards. The three libraries don't search the same way, so one domain alone doesn't work identically on all three.

How each library searches: Meta searches by Page name or keyword · Google Ads Transparency searches by domain · LinkedIn searches by company name (the generator link is global — use LinkedIn's own Country filter inside the library for one market, and treat the generated link as live-unverified until it loads for you).

No backend is combing the libraries: search filters the captured file on this page and builds the library links for you to open — it does not fetch live ads. This is a static page: the 36 July 2026 ads are baked in, and there is no server, background job, or instruction anywhere that searches Meta, Google or LinkedIn for a brand automatically. Actually combing the libraries for a brand would need a separate backend service, browser automation, or a paid ad-data service — none of that is part of this prototype, and nothing here should be read as if it were happening behind the scenes.

2 · Top ads — visual cards

Compact, image-forward cards — brand header with its captured count, format tabs with counts, and the creative up front with a days-running badge and published reach overlaid where a library published it. Each card is rebuilt from the audit's own creative notes (the July dataset has no real image files), so every mock is labelled as one, on the card; a screenshot you capture replaces the mock. Click any card to open its full swipe-file card below. No playbook panel — just the cards.

Reach is overlaid only where a library published it (in this file, the 5 TikTok HK video ads) — every other card shows no reach, never an invented one. There is no spend overlay: Meta, Google and LinkedIn publish no spend for commercial ads, and this page does not model an estimate. Library counts are manual records of the number the library page showed when you looked — always shown with their source and date, never as a live figure. Full details, creative notes and start-date fields for every captured ad are in the swipe file in section 4, which follows the brand selected here.

3 · How winning is judged

There is no performance feed for commercial ads, so “winning” here is a proxy — labelled as one, with the thresholds stated up front.

Long-running = likely working

Enter the “started running” date shown in the library for each ad. 30+ days flags it as a Long-runner; 90+ days is the stronger signal. Until a date is entered, longevity shows as “Not recorded” — this dataset (July 2026) captured no start dates, so none are invented.

Variations on one angle = scaling it

Several ads pushing the same product or hook means the advertiser is investing behind that angle. In this file: Amazon runs the same Amazon Quick / Q Business creative across all six SEA markets, and TikTok repeats its “Level Up Your Advertising” hook across Philippine video ads.

New this week = survived its first test

An ad whose start date falls within 7 days of your capture date gets the New this week flag. If it's still running at the next weekly capture, it passed its first test. Libraries don't send alerts — spotting launches means capturing weekly and comparing.

Published reach = real audience data

Where a library published reach, it's shown on the card. In this file only the 5 TikTok HK video ads carry it — the highest is “name a more emotionally scarring movie 😭” at 1M–10M unique users. Everywhere else, reach reads “Not published”.

What the libraries do not publish for commercial ads
  • Spend: not published by Meta, Google or LinkedIn. No spend column is shown, and no “estimated spend” is invented — there is no estimation model behind this prototype.
  • CTR / conversions: not published on any of the three libraries.
  • Age & gender: not published outside EU/UK-delivered ads. This audit covers CN/HK/SEA, so every card reads “Age/gender: not published outside EU/UK”. Country is shown — it's the ad's market.
  • No official pull: Meta's Ad Library API covers political/issue and EU/UK ads only; Google has no public API for commercial ads. Capture stays manual for now — that's why Quick capture below works from a screenshot alone, with no form to fill in.

4 · The swipe file

Split by format, sortable, filterable — and it follows the brand you looked up in section 1 or picked in Top ads: while a brand is active, only that brand's ads show here, the format counts and the “Showing” line count that brand only, and “Clear filter” above the cards brings back the full file. Carousel and Creator-led are shown as empty states rather than filled with invented entries — this audit captured no carousels, and no ad is explicitly flagged creator-led (the closest style, “UGC/Authentic”, doesn't appear in the data either).

Tip: add a start date on any card to switch on its days-running and flags.

5 · Capture an ad — a screenshot is enough

Found a new ad in a library? Don't fill in a form. Screenshot it, drop the screenshot in below, confirm the brand, and save — that's a complete capture. It appears straight away in the swipe file and in that brand's Top ads, with the screenshot as its thumbnail. Add the words and dates later only if you want them, via “Add details” on its card. Entries added in the browser (screenshots included) are kept in this browser tab only and reset on reload — download the CSV above to keep the text copy (the CSV holds the text, not the image).
